# Website Delivery Agreement — Lotus Bakery (FICTIONAL DEMO DOCUMENT)

This is a fictional agreement between Studio North (the developer) and Lotus Bakery (the client). It exists only for the CallPilot AI demonstration.

Scope: Studio North will design and build a five-page website for Lotus Bakery: Home, Menu, About, Order Online and Contact. The package includes mobile layouts and one round of design revisions.

Delivery: The first working version will be delivered on Friday, provided the client sends final product images and menu text by Tuesday. If the images arrive late, delivery moves back by the same number of working days.

Product catalogue: The package includes manual entry of up to 25 products. Bulk product upload via spreadsheet import is NOT included; it can be added as an extra for an additional fee, quoted separately.

Payments: 50% deposit on signing, 50% on launch. Studio North will never ask for OTPs, passwords or bank PINs. All payments go through the invoice link only.

Support: Thirty days of bug-fix support after launch. New features after launch are billed hourly.
